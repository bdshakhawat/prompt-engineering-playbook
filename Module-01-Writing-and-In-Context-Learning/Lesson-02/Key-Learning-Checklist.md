# Common Pitfalls to Avoid

- [ ] Restarting conversations unnecessarily.
- [ ] Assuming previous AI outputs disappear.
- [ ] Ignoring accumulated conversational context.
- [ ] Allowing factual errors to propagate across iterations.
- [ ] Using overly broad correction instructions.
- [ ] Assuming iterative refinement automatically fixes earlier mistakes.

---

# Physics AI Best Practices

When refining Physics content with AI, I will:

- [x] Start with a functional first draft.
- [x] Improve one aspect at a time.
- [x] Correct scientific errors immediately.
- [x] Verify formulas and definitions after every refinement.
- [x] Review laboratory safety instructions separately.
- [x] Monitor conversation history throughout long interactions.
- [x] Continue refining until educational quality and teaching voice are both achieved.
