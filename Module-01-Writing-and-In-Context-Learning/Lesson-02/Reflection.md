# Reflection

## What Changed My Perspective

This lesson fundamentally changed how I think about what actually constitutes a prompt.

Before this lesson, I assumed that every message I sent to an AI model was an independent instruction. If an output needed improvement, I believed the best approach was to rewrite the original prompt and begin a completely new conversation.

I now understand that an entire conversation functions as one continuously evolving prompt. Every user instruction, every AI response, and every refinement collectively shape the model's future behaviour.

This realization shifted my understanding of prompt engineering. It is not only about writing effective prompts—it is equally about managing conversations strategically.

---

## Key Insight

The most valuable insight from this lesson is that iterative refinement is fundamentally different from repeatedly rewriting prompts.

When I provide follow-up instructions within the same conversation, the AI does not interpret them in isolation. Instead, it considers them alongside everything that has already been discussed.

Its previous responses become additional context that helps reduce ambiguity and improve continuity.

However, this accumulated context also introduces responsibility.

If earlier responses contain inaccurate information, weak reasoning, or an inappropriate tone, those issues may continue influencing future outputs unless they are explicitly corrected.

Conversation history is therefore both an advantage and a responsibility.

## Relevance to Physics Education

As someone preparing for a career as a Physics AI Subject Matter Expert, this lesson has immediate practical value.

When developing AI-assisted lesson plans, laboratory instructions, assessment materials, classroom announcements, or parent communications, I no longer need to expect perfection from the initial prompt.

This iterative refinement process closely mirrors effective classroom practice, where meaningful learning is achieved through continuous feedback and improvement rather than a single attempt.
