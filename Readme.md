# 🔬 Physics AI Evaluation

One of my primary areas of interest is evaluating AI-generated Physics responses.

I am developing a structured evaluation mindset based on criteria such as:

```text
Scientific Accuracy
        +
Mathematical Correctness
        +
Reasoning Quality
        +
Instruction Following
        +
Hallucination Detection
        +
Audience Appropriateness
        +
Educational Value

The goal is not simply to determine whether an AI answer is correct.

The deeper objective is to understand:

> What is correct, what is incorrect, why the error occurred, how it should be corrected, and whether the response is appropriate for the intended learner.

This capability is directly relevant to Physics AI training and Subject Matter Expert work.

# 🧪 Practical Prompt Engineering

This repository emphasizes learning through experimentation.

For each major technique, I aim to:

1. Understand the concept.
2. Reproduce the technique.
3. Test it with a practical prompt.
4. Evaluate the resulting output.
5. Identify weaknesses.
6. Refine the prompt.
7. Apply the technique to Physics.
8. Document the findings.
9. Convert the lesson into reusable knowledge.

This creates a continuous cycle:

Learn
  ↓
Experiment
  ↓
Evaluate
  ↓
Refine
  ↓
Apply to Physics
  ↓
Document
  ↓
Reuse
```
