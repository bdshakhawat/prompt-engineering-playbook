# Lesson Summary
## Module 2 – Lesson 5: Automated Search for Solutions

### One-Sentence Summary

Generative AI becomes significantly more powerful when we generate multiple candidate solutions, automatically test them against objective criteria, score and rank the valid candidates, and select the best one.

---

## Core Idea

The traditional AI workflow is:

```text
Prompt → One Answer
========================
The lesson introduces a more powerful workflow:

Prompt
  ↓
Generate Many Solutions
  ↓
Test
  ↓
Filter
  ↓
Score
  ↓
Rank
  ↓
Select Best Solution
The Most Important Principle

The technique is particularly valuable when:

A solution is difficult or expensive to generate, but relatively easy to check.

When this condition exists, generative AI can explore many possible solutions and an evaluator can identify the strongest candidate.

Software Example

Instead of generating one implementation:

AI → Code

we can generate:

AI → Code 1
   → Code 2
   → Code 3
   → ...
   → Code 1000

Each version can be tested automatically.

Correct solutions can then be ranked according to:

Speed
Efficiency
Resource usage
Maintainability
Other performance criteria

The system can therefore search for a high-quality implementation automatically.

General Algorithm
1. Define the problem.
2. Define what makes a solution correct.
3. Define what makes a solution better.
4. Generate multiple candidate solutions.
5. Test each candidate.
6. Reject candidates that fail.
7. Score candidates that pass.
8. Rank the candidates.
9. Select the strongest candidate.
10. Perform human review when necessary.
Human Evaluation

Automated testing is not always possible.

When objective testing is difficult, we can still generate many solutions and have humans evaluate them.

This creates:

Generate Many
      ↓
Human Review
      ↓
Filter
      ↓
Rank
      ↓
Select

Human evaluation can also be used after automated evaluation.

Physics Application

Physics is highly suitable for this approach because many generated solutions can be checked using objective scientific criteria.

Examples include:

Dimensional consistency

Numerical verification

Experimental data

A Physics AI workflow could therefore be:

      ↓
Score
      ↓

      ↓
Human Physics SME Review
      ↓
Final Answer

"Write one perfect prompt."

Instead, prompt engineering can involve designing a complete AI workflow.

For example:

Generation Prompt

Scoring Rubric
       ↓
Selection Logic

This represents a more advanced approach to working with generative AI.
