# Key Learning Checklist

## Module 2, Lesson 1: Exploiting Generation

Use this checklist to confirm mastery of the lesson's core concepts before moving on.

- [ ] I can explain why a single AI-generated output should be treated as a perspective rather than a definitive answer.
- [ ] I can describe the evidence for this: running the identical prompt in a new conversation produces a different result each time.
- [ ] I can define **exploiting generation** and explain why it costs very little extra time relative to the quality gain it produces.
- [ ] I can explain why the "generate and accept" pattern risks allowing critical thinking and creative judgment to atrophy.
- [ ] I can describe how comparing multiple outputs re-engages judgment, aesthetics, and personal voice.
- [ ] I can explain the difference between selecting one output wholesale and merging the strongest elements from multiple outputs.
- [ ] I can explain why the lecture rejects "time saved" as a meaningful measure of AI's value, and what it proposes instead.
- [ ] I can apply exploiting generation to a physics teaching task (e.g., generating multiple explanations or quiz questions before selecting or merging the best one).
- [ ] I can identify the additional risk this technique carries in a technical subject like physics — that more generated options means more chances for a plausible-but-incorrect version to appear — and explain why fact-checking must happen before comparing for style.
- [ ] I have completed all six lesson files: Notes, Physics-AI-Application, Prompt-Engineering-Case-Study, Reflection, Lesson-Summary, and this checklist.

## Self-Check Question

> I generate three different explanations of the same physics concept using the identical prompt in three separate conversations. Before I compare them for classroom fit and tone, what should I do first, and why?

**My answer should reference:** fact-checking each of the three versions independently for physics accuracy before comparing them for clarity, analogy quality, or tone — since exploiting generation multiplies the number of perspectives available, but does not guarantee that all of them are factually correct. A confident, well-written explanation can still contain a subtle error.
