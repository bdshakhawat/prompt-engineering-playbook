Lesson Summary
Module 2, Lesson 4: Separating Evaluation from Generation

One-Sentence Summary: Generate evaluation metrics in a separate, independent conversation from the one used to generate solution options — this avoids bias from assumptions baked into the generation process, and combining independently generated options and metrics produces a structured, professional-quality comparison.

The Core Problem

When evaluation criteria are generated in the same conversation that already produced a set of solutions, those criteria risk being unconsciously shaped to flatter the existing options, rather than reflecting what genuinely matters for the task.

The Core Technique
Generate solution options in one conversation.
In a separate, independent conversation, generate evaluation metrics using an explicit "don't list solutions, only metrics" instruction, with the task description clearly separated (e.g., with dotted lines) as context rather than as an instruction to act on.
Reformat all generated options consistently, to prevent presentation differences from biasing the evaluation.
Combine the reformatted options and the independently generated metrics in a final prompt: "Evaluate these options using these metrics."
The Demonstration

Using the camping cake-baking problem, the instructor generated five evaluation metrics (ease of preparation, cooking time, consistency, supervision required, risk of burning) independently of the solution options, then combined both to produce a structured, method-by-method evaluation — which also surfaced new solution options (foil packet cake, steamed cake) that hadn't appeared in the original generation round.

Extending the Technique

The final evaluation can be further organized into a table, evaluation matrix, or quadrant chart — a capability the instructor compares directly to expensive, specialized consulting deliverables, now achievable quickly and independently.

Physics Teaching Connection

This technique applies directly to comparing physics teaching approaches, lab designs, or assessment formats: generating evaluation metrics (misconception-targeting, time required, equipment needs, engagement level) independently of the specific teaching methods being considered produces a more genuinely objective, criteria-based comparison — turning an intuitive teaching choice into a defensible, structured decision.
